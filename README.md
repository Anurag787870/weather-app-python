# 🌦️ Weather App using Python

A simple Weather App built with Python that fetches live weather data using the OpenWeather API.

## Features

- Search weather by city
- Current temperature
- Humidity
- Wind speed
- Weather condition
- Error handling for invalid cities

## Technologies Used

- Python
- Requests
- REST API
- JSON

## Installation

pip install requests

## Run

python weather_app.py
